# Startup Idea Validator

An AI-powered web application that evaluates startup ideas using **LLM reasoning and real-time market research**. The system analyzes a startup concept and provides structured feedback on strengths, risks, and monetization possibilities.

Built using **LangChain agents, Groq LLM, Tavily search, and Streamlit**.

---

## Overview

Startup Idea Validator allows users to input a startup concept and receive an automated evaluation generated by an AI agent.

The application performs:

- AI-based reasoning on the idea
- optional live market research
- structured evaluation output

The final analysis includes:

- strengths of the idea  
- weaknesses or limitations  
- potential risks  
- monetization possibilities  
- overall viability score  

This project demonstrates how **LLM agents can combine reasoning with external tools** to support decision-making workflows.

## Tech Stack

- **Python**

- **Groq LLM (Llama-3.3-70B)** – language model
- **Tavily Search API** – market research tool

## Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/startup-idea-validator.git
cd startup-idea-validator
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Environment Variables

Create a `.env` file in the project directory and add your API keys:

```
GROQ_API_KEY=your_groq_api_key
TAVILY_API_KEY=your_tavily_api_key
```

---

## Running the Application

Start the Streamlit app:

```bash
streamlit run app.py
```

The application will open in your browser.

---

## How It Works

1. User enters a startup idea and target users.
2. The LangChain agent processes the request.
3. If required, the agent performs market research using Tavily.
4. The LLM generates an evaluation.
5. Results are displayed in structured sections.
